For otus php professional course homeworks

# Описание
В файле solution имеются три функции слияния двух отсортированных связанных списков

Во всех трех функциях скорость выполнения составляет O(n), так как выполнение осуществляется линейно, без вложенных циклов с обработкой каждого входящего n посредством квадрата от n, что составило бы O(n2), или ветвлящихся на каждом шаге рекурсий, что составило бы O(2n).

Потребление памяти в первых двух функциях составляет O(n), так как мы всегда создаем новый связанный список с элементами из первых двух связанных списков, память других переменных составляет O(1), так как не зависит от объема входящих данных.

Потребление памяти в рекурсивной функции составляет O(n + O(1) * n), так как на каждом шаге рекурсии происходит создание новых вспомогательных переменных, которые в первых двух функциях потребляли память константно, вне зависимости от объема входящих данных.

В первой и третьей функции конец связанного списка проверяется в конструкции (null === $listOne->next || null === $listTwo->next). Оператор "или" был выбран, так как существует вероятность того, что один из списков окажется длиннее/короче другого списка, и по достижении концов одного из списков обработку нужно прекращать.

Данный нюанс учтен в функции mergeTwoListWithDifferentLength, в которой, если длина входящих списков отличается, то по завершении одного из списков, в $mergedListNode записываются значения из списка большей длины.
