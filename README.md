# Описание
В файле solution приведена функция mergeTwoList, сливающая два связанных списка в один. Функция производит предварительное неупорядоченное слияние двух связанных списков, с последующим разбиением на подсписки с последующим слиянием в рамках алгоритма сортировки слиянием. Функция по времени отрабатывает за log(n log n). Сложность по памяти составляет O(n), так как размер нового связянного списка растет линейно с объемом входящих данных.
